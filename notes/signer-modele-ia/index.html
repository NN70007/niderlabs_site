Signer un modèle d'IA : pourquoi et commentSigning an AI model: why and howFirmar un modelo de IA: por qué y cómoEin KI-Modell signieren: warum und wie

Les organisations signent leurs logiciels depuis longtemps. Les modèles d'IA, eux, arrivent souvent par un simple téléchargement. Pourtant, un modèle est une dépendance comme une autre, et parfois plus dangereuse.

Organisations have signed their software for a long time. AI models, on the other hand, often arrive through a plain download. Yet a model is a dependency like any other, and sometimes a more dangerous one.

Las organizaciones han firmado su software durante mucho tiempo. Los modelos de IA, por otro lado, a menudo llegan a través de una descarga sencilla. Sin embargo, un modelo es una dependencia como cualquier otra, y a veces una más peligrosa.

Organisationen haben ihre Software schon lange signiert. KI-Modelle hingegen werden oft durch einen einfachen Download bereitgestellt. Doch ein Modell ist eine Abhängigkeit wie jede andere, und manchmal eine gefährlichere.

Un fichier de modèle n'est pas inerteA model file is not inertUn archivo de modelo no es inerteEine Modelldatei ist nicht inert

Certains formats historiques de modèles, fondés sur le mécanisme de sérialisation « pickle » de Python, peuvent exécuter du code au moment du chargement. Charger un tel fichier d'origine inconnue revient à lancer un programme d'origine inconnue. Les formats plus récents, comme safetensors ou GGUF, ne contiennent que des données, ce qui réduit fortement ce risque.

Some historical model formats, built on Python's "pickle" serialisation, can execute code when loaded. Loading such a file from an unknown source amounts to running a program from an unknown source. Newer formats, such as safetensors or GGUF, contain only data, which greatly reduces this risk.

Algunos formatos de modelos históricos, basados en la serialización "pickle" de Python, pueden ejecutar código al cargarse. Cargar un archivo de una fuente desconocida equivale a ejecutar un programa de una fuente desconocida. Los formatos más recientes, como safetensors o GGUF, contienen solo datos, lo que reduce considerablemente este riesgo.

Einige ältere Modellformate, die auf der „pickle“-Serialisierung von Python beruhen, können beim Laden Code ausführen. Eine solche Datei unbekannter Herkunft zu laden, heißt, ein Programm unbekannter Herkunft zu starten. Neuere Formate wie safetensors oder GGUF enthalten nur Daten, was dieses Risiko stark verringert.

Mais même un fichier inerte peut être un problème. Un modèle remplacé, dégradé ou simplement d'une autre version donne d'autres résultats. Dans un métier où le texte compte, il faut savoir exactement quel modèle a produit quoi.

But even an inert file can be a problem. A model that has been replaced, degraded or is simply another version gives different results. In a profession where text matters, you need to know exactly which model produced what.

Pero incluso un archivo inerte puede ser un problema. Un modelo sustituido, degradado o simplemente de otra versión da otros resultados. En una profesión en la que el texto importa, hay que saber exactamente qué modelo produjo qué.

Doch auch eine inerte Datei kann ein Problem sein. Ein ersetztes, verschlechtertes oder einfach anderes Modell liefert andere Ergebnisse. In einem Beruf, in dem der Text zählt, muss man genau wissen, welches Modell was erzeugt hat.

Empreinte ou signature ?Fingerprint or signature?¿Huella o firma?Prüfsumme oder Signatur?

Les deux répondent à des questions différentes.

They answer different questions.

Responden a preguntas diferentes.

Sie beantworten unterschiedliche Fragen.

  • L'empreinte (par exemple SHA-256) répond à : « ce fichier est-il identique à celui attendu ? ». Elle suffit quand on dispose d'une liste fermée de fichiers connus, obtenue par un canal de confiance.
  • A fingerprint (for instance SHA-256) answers: "is this file identical to the expected one?". It is enough when you have a closed list of known files, obtained through a trusted channel.
  • Una huella (por ejemplo, SHA-256) responde: "¿Es este archivo idéntico al esperado?". Es suficiente cuando se tiene una lista cerrada de archivos conocidos, obtenidos a través de un canal de confianza.
  • Eine Prüfsumme (zum Beispiel SHA-256) beantwortet: "Ist diese Datei identisch mit der erwarteten?". Sie reicht aus, wenn Sie eine geschlossene Liste bekannter Dateien haben, die über einen vertrauenswürdigen Kanal erhalten wurden.
  • La signature (par exemple Ed25519) répond à : « ce fichier a-t-il été publié par celui qui détient cette clé ? ». Elle permet d'accepter de nouvelles versions sans mettre à jour une liste, tant qu'elles sont signées par la bonne clé.
  • A signature (for instance Ed25519) answers: "was this file published by whoever holds this key?". It lets you accept new versions without updating a list, as long as they are signed with the right key.
  • Una firma (por ejemplo, Ed25519) responde: "¿fue publicado este archivo por quien posee esta clave?". Permite aceptar nuevas versiones sin actualizar una lista, siempre que estén firmadas con la clave correcta.
  • Eine Signatur (zum Beispiel Ed25519) beantwortet: "wurde diese Datei von demjenigen veröffentlicht, der diesen Schlüssel besitzt?". Sie ermöglicht Ihnen, neue Versionen zu akzeptieren, ohne eine Liste zu aktualisieren, solange sie mit dem richtigen Schlüssel signiert sind.

En pratique, les deux se combinent : signature pour les modèles d'un éditeur, liste d'empreintes pour des modèles publics que l'éditeur ne peut pas signer à la place de leur auteur.

In practice, the two are combined: signatures for a vendor's own models, a fingerprint list for public models that the vendor cannot sign on their author's behalf.

En la práctica, las dos se combinan: firmas para los modelos propios del proveedor, una lista de huellas para los modelos públicos que el proveedor no puede firmar en nombre de sus autores.

In der Praxis werden beide kombiniert: Signaturen für die eigenen Modelle eines Anbieters, eine Prüfsummenliste für öffentliche Modelle, die der Anbieter nicht anstelle ihres Urhebers signieren kann.

Vérifier avant de charger, pas aprèsVerify before loading, not afterVerifique antes de cargar, no despuésÜberprüfen Sie vor dem Laden, nicht danach

La vérification n'a de valeur que si elle conditionne le chargement. Le logiciel doit calculer l'empreinte ou vérifier la signature, puis refuser le fichier en cas d'écart, avec un message clair, sans proposer de « charger quand même ». Un contrôle qui peut être contourné d'un clic n'est pas un contrôle.

Verification is only worth something if loading depends on it. The software must compute the fingerprint or check the signature, then refuse the file if anything differs, with a clear message and no "load anyway" option. A check that can be bypassed with one click is not a check.

La verificación solo vale algo si la carga depende de ella. El software debe calcular la huella o verificar la firma, luego rechazar el archivo si algo difiere, con un mensaje claro y sin opción de "cargar de todos modos". Una verificación que se puede eludir con un clic no es una verificación.

Eine Prüfung ist nur dann etwas wert, wenn das Laden von ihr abhängt. Die Software muss die Prüfsumme berechnen oder die Signatur prüfen und die Datei bei jeder Abweichung ablehnen, mit einer klaren Meldung und ohne Option „trotzdem laden“. Eine Prüfung, die sich mit einem Klick umgehen lässt, ist keine Prüfung.

Pour les modèles publics, figez aussi la version : téléchargez une révision précise, pas « la dernière ». Un dépôt public peut changer ; une révision figée et son empreinte, non.

For public models, pin the version too: download a specific revision, not "the latest". A public repository can change; a pinned revision and its fingerprint cannot.

Para los modelos públicos, también fije la versión: descargue una revisión específica, no "la última". Un repositorio público puede cambiar; una revisión fijada y su huella no pueden.

Legen Sie bei öffentlichen Modellen auch die Version fest: Laden Sie eine bestimmte Revision herunter, nicht „die neueste“. Ein öffentliches Repository kann sich ändern; eine festgelegte Revision und ihre Prüfsumme nicht.

Garder la clé hors de portéeKeep the key out of reachMantener la clave fuera de alcanceDen Schlüssel unerreichbar halten

Une signature ne vaut que ce que vaut la protection de la clé privée. Elle ne doit jamais se trouver dans un dépôt de code, ni sur une machine exposée. Seule la clé publique est livrée avec le logiciel. Prévoyez aussi le jour où la clé devra être remplacée : comment le logiciel apprendra-t-il à faire confiance à la nouvelle ?

A signature is only as good as the protection of the private key. It must never sit in a code repository, nor on an exposed machine. Only the public key ships with the software. Plan also for the day the key must be replaced: how will the software learn to trust the new one?

Una firma solo es tan buena como la protección de la clave privada. Nunca debe estar en un repositorio de código, ni en una máquina expuesta. Solo la clave pública se envía con el software. Planifique también para el día en que la clave deba ser reemplazada: ¿cómo aprenderá el software a confiar en la nueva?

Eine Signatur ist nur so gut wie der Schutz des privaten Schlüssels. Er darf niemals in einem Code-Repository liegen, noch auf einem exponierten Gerät. Nur der öffentliche Schlüssel wird mit der Software ausgeliefert. Planen Sie auch für den Tag, an dem der Schlüssel ersetzt werden muss: Wie wird die Software lernen, dem neuen zu vertrauen?

L'étape suivante : la validation par l'organisationThe next step: approval by the organisationEl siguiente paso: aprobación por parte de la organizaciónDer nächste Schritt: Genehmigung durch die Organisation

Le modèle idéal pour une grande organisation est celui où l'éditeur signe ce qu'il publie, et où l'organisation décide en plus, par sa propre liste, quels modèles sont autorisés sur ses postes. C'est la même logique que la liste blanche d'applications, appliquée aux modèles d'IA.

The ideal model for a large organisation is one where the vendor signs what it publishes, and the organisation additionally decides, through its own list, which models are allowed on its machines. It is the same logic as application allow-listing, applied to AI models.

El modelo ideal para una gran organización es aquel en el que el proveedor firma lo que publica, y la organización decide adicionalmente, a través de su propia lista, qué modelos están permitidos en sus equipos. Es la misma lógica que la lista de aplicaciones permitidas, aplicada a los modelos de IA.

Das ideale Modell für eine große Organisation ist eines, bei dem der Anbieter unterzeichnet, was er veröffentlicht, und die Organisation zusätzlich über ihre eigene Liste entscheidet, welche Modelle auf ihren Geräten zugelassen sind. Es ist dieselbe Logik wie bei der Anwendung von Allow-Listing, angewendet auf KI-Modelle.

NiderVoice applique ces règles : les modèles de NiderLabs sont signés en Ed25519, les modèles publics comme Whisper sont vérifiés par une liste fermée d'empreintes SHA-256, et tout autre fichier est refusé. Voir la page Modèles.

NiderVoice applies these rules: NiderLabs models are signed with Ed25519, public models such as Whisper are checked against a closed list of SHA-256 fingerprints, and any other file is refused. See the Models page.

NiderVoice aplica estas normas: los modelos de NiderLabs están firmados con Ed25519, los modelos públicos como Whisper se comprueban frente a una lista cerrada de huellas SHA-256, y cualquier otro archivo se rechaza. Consulte la página de Modelos.

NiderVoice wendet diese Regeln an: NiderLabs-Modelle werden mit Ed25519 signiert, öffentliche Modelle wie Whisper werden gegen eine geschlossene Liste von SHA-256-Prüfsummen überprüft, und jede andere Datei wird abgelehnt. Siehe die Modellseite.
