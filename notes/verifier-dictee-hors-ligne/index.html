Comment vérifier qu'un logiciel de dictée n'envoie rienHow to check that dictation software sends nothingCómo verificar que el software de dictado no envía nadaWie man überprüft, dass Diktiersoftware nichts sendet

« Tout est traité en local » est une phrase facile à écrire. Voici cinq contrôles que n'importe quel service informatique peut faire en une heure, sans outil exotique, pour le vérifier.

"Everything is processed locally" is an easy sentence to write. Here are five checks any IT department can run in an hour, with no exotic tools, to verify it.

"Todo se procesa localmente" es una frase fácil de escribir. Aquí tiene cinco comprobaciones que cualquier departamento de informática puede realizar en una hora, sin herramientas exóticas, para verificarlo.

„Alles wird lokal verarbeitet“ ist ein Satz, der sich leicht schreiben lässt. Hier sind fünf Prüfungen, die jede IT-Abteilung in einer Stunde ohne exotische Werkzeuge durchführen kann, um ihn zu überprüfen.

1. Couper le réseau1. Cut the network1. Corte la red1. Das Netzwerk trennen

Le test le plus simple est aussi le plus parlant. Débranchez le câble, coupez le Wi-Fi, puis dictez. Un logiciel réellement local fonctionne à l'identique. S'il ralentit, échoue ou attend une connexion, c'est qu'une partie du traitement se fait ailleurs.

The simplest test is also the most telling. Unplug the cable, turn off Wi-Fi, then dictate. Truly local software works exactly the same. If it slows down, fails or waits for a connection, part of the processing happens elsewhere.

El test más simple es también el más revelador. Desconecte el cable, apague el Wi-Fi y luego dicte. Un software verdaderamente local funciona exactamente igual. Si se ralentiza, falla o espera una conexión, parte del procesamiento ocurre en otro lugar.

Der einfachste Test ist auch der aussagekräftigste. Ziehen Sie das Kabel, schalten Sie das WLAN aus und diktieren Sie. Wirklich lokale Software funktioniert genau gleich. Wird sie langsamer, schlägt sie fehl oder wartet sie auf eine Verbindung, findet ein Teil der Verarbeitung anderswo statt.

Ce test ne suffit pas à lui seul : un logiciel peut fonctionner hors ligne et envoyer ce qu'il a gardé dès que la connexion revient. D'où les contrôles suivants.

This test is not enough on its own: software can work offline and send what it kept as soon as the connection returns. Hence the next checks.

Esta prueba no basta por sí sola: un programa puede funcionar sin conexión y enviar lo que ha guardado en cuanto vuelve la conexión. De ahí las comprobaciones siguientes.

Dieser Test allein genügt nicht: Eine Software kann offline funktionieren und das Gespeicherte senden, sobald die Verbindung zurückkehrt. Daher die folgenden Prüfungen.

2. Observer les connexions du processus2. Watch the process's connections2. Supervise las conexiones del proceso2. Die Verbindungen des Prozesses beobachten

Sous Windows, le Moniteur de ressources (onglet Réseau) montre, processus par processus, les adresses contactées. En PowerShell, la commande suivante liste les connexions ouvertes par un programme donné :

On Windows, Resource Monitor (Network tab) shows, process by process, the addresses contacted. In PowerShell, the following command lists the connections opened by a given program:

En Windows, el Monitor de recursos (pestaña Red) muestra, proceso por proceso, las direcciones contactadas. En PowerShell, el siguiente comando lista las conexiones abiertas por un programa determinado:

Auf Windows zeigt der Ressourcenmonitor (Registerkarte "Netzwerk") prozessweise die kontaktierten Adressen an. In PowerShell listet der folgende Befehl die von einem bestimmten Programm geöffneten Verbindungen auf:

Get-NetTCPConnection | Where-Object OwningProcess -eq (Get-Process MyDictation).Id

Dictez pendant quelques minutes en surveillant. Pendant la dictée, la liste doit rester vide. Notez aussi ce qui se passe au démarrage : une recherche de mise à jour peut être légitime, à condition d'être documentée et désactivable.

Dictate for a few minutes while watching. During dictation, the list should stay empty. Also note what happens at start-up: an update check can be legitimate, provided it is documented and can be switched off.

Dictar durante unos minutos mientras observa. Durante la dictación, la lista debe permanecer vacía. También tenga en cuenta lo que ocurre al inicio: una comprobación de actualizaciones puede ser legítima, siempre que esté documentada y pueda desactivarse.

Diktieren Sie einige Minuten lang, während Sie beobachten. Während der Diktat sollte die Liste leer bleiben. Notieren Sie auch, was beim Start passiert: Eine Aktualisierungsprüfung kann legitim sein, sofern sie dokumentiert und abschaltbar ist.

3. Bloquer, puis confirmer3. Block, then confirm3. Bloquee, luego confirme3. Blockieren, dann bestätigen

Créez dans le pare-feu une règle qui interdit toute connexion sortante à l'exécutable, puis utilisez le logiciel une journée normale. S'il continue de fonctionner sans erreur ni avertissement, il n'a pas besoin du réseau pour travailler. C'est aussi la configuration que nous recommandons en production pour un outil de dictée.

Create a firewall rule that blocks all outbound connections for the executable, then use the software for a normal day. If it keeps working with no error or warning, it does not need the network to do its job. This is also the configuration we recommend in production for a dictation tool.

Cree una regla de firewall que bloquee todas las conexiones salientes para el ejecutable, luego utilice el software durante un día normal. Si sigue funcionando sin errores ni advertencias, no necesita la red para realizar su trabajo. Esta también es la configuración que recomendamos en producción para una herramienta de dictado.

Erstellen Sie eine Firewall-Regel, die alle ausgehenden Verbindungen für die ausführbare Datei blockiert, und verwenden Sie die Software dann für einen normalen Arbeitstag. Wenn sie ohne Fehler oder Warnung weiter funktioniert, benötigt sie keine Netzwerkverbindung, um ihre Aufgabe zu erfüllen. Dies ist auch die Konfiguration, die wir für ein Diktat-Tool in der Produktion empfehlen.

Pour aller plus loin, une capture réseau (Wireshark, par exemple) sur un poste de test, filtrée sur les requêtes DNS, montre si le logiciel cherche à résoudre des noms de domaine, même sans réussir à s'y connecter.

To go further, a network capture (Wireshark, for instance) on a test machine, filtered on DNS queries, shows whether the software tries to resolve domain names, even without managing to connect.

A continuación, un análisis de red (Wireshark, por ejemplo) en una máquina de prueba, filtrado por consultas DNS, muestra si el software intenta resolver nombres de dominio, incluso sin conseguir conectarse.

Um weiterzugehen, zeigt eine Netzwerkaufzeichnung (z. B. mit Wireshark) auf einem Testgerät, gefiltert auf DNS-Anfragen, ob die Software versucht, Domainnamen aufzulösen, selbst wenn sie nicht verbunden werden kann.

4. Regarder le presse-papiers4. Look at the clipboard4. Revise el portapapeles4. Die Zwischenablage prüfen

C'est la fuite que presque tout le monde oublie. Beaucoup de logiciels de dictée insèrent le texte en le copiant dans le presse-papiers puis en simulant un collage. Or Windows peut conserver un historique du presse-papiers (Windows + V) et le synchroniser entre appareils via le compte de l'utilisateur. Le texte dicté peut alors quitter le poste sans que le logiciel de dictée n'ait rien envoyé lui-même.

This is the leak almost everyone forgets. Many dictation programs insert text by copying it to the clipboard and simulating a paste. But Windows can keep a clipboard history (Windows + V) and sync it across devices through the user's account. Dictated text can then leave the machine without the dictation software sending anything itself.

Es la fuga que casi todo el mundo olvida. Muchos programas de dictado insertan el texto copiándolo en el portapapeles y simulando un pegado. Pero Windows puede conservar un historial del portapapeles (Windows + V) y sincronizarlo entre dispositivos mediante la cuenta del usuario. El texto dictado puede entonces salir del equipo sin que el programa de dictado haya enviado nada por sí mismo.

Dies ist der Leak, den fast jeder vergisst. Viele Diktierprogramme fügen Text ein, indem sie ihn in die Zwischenablage kopieren und ein Einfügen simulieren. Aber Windows kann eine Zwischenablage-Historie speichern (Windows + V) und sie über die Benutzerkonten auf Geräten synchronisieren. Diktierter Text kann dann das Gerät verlassen, ohne dass die Diktiersoftware selbst etwas sendet.

Le test : activez l'historique, dictez une phrase, puis ouvrez Windows + V. Si la phrase y figure, elle peut aussi être synchronisée. Windows prévoit des formats qui demandent d'exclure un contenu de l'historique et de la synchronisation ; un logiciel soigneux les utilise, et vide le presse-papiers après le collage. Côté organisation, une stratégie de groupe permet de désactiver l'historique et la synchronisation du presse-papiers.

The test: turn history on, dictate a sentence, then open Windows + V. If the sentence is there, it can also be synced. Windows provides formats that ask for content to be excluded from history and sync; careful software uses them, and clears the clipboard after pasting. On the organisation side, a group policy can turn off clipboard history and sync.

El test: active el historial, dicte una frase y, a continuación, abra Windows + V. Si la frase está allí, también puede sincronizarse. Windows proporciona formatos que solicitan que el contenido se excluya del historial y la sincronización; un software cuidadoso los utiliza y borra el portapapeles después de pegar. Por el lado de la organización, una directiva de grupo puede desactivar el historial y la sincronización del portapapeles.

Der Test: Aktivieren Sie die Verlaufsfunktion, diktieren Sie einen Satz und öffnen Sie dann Windows + V. Wenn der Satz dort erscheint, kann er auch synchronisiert werden. Windows bietet Formate an, die verlangen, dass Inhalte vom Verlauf und der Synchronisierung ausgeschlossen werden; sorgfältige Software nutzt diese und leert die Zwischenablage nach dem Einfügen. Auf Organisationsebene kann eine Gruppenrichtlinie die Verlaufsfunktion der Zwischenablage und die Synchronisierung deaktivieren.

5. Lire ce qui reste sur le disque5. Read what stays on disk5. Lea lo que permanece en el disco5. Lesen, was auf der Festplatte bleibt

Après une séance de dictée, cherchez les fichiers récemment modifiés dans les dossiers du logiciel (AppData, ProgramData, dossier d'installation) : journaux, historiques, enregistrements audio, caches. Ouvrez les journaux et cherchez-y une phrase que vous avez dictée. Un logiciel sobre ne garde ni le son ni le texte, et ses journaux décrivent des événements, jamais le contenu dicté.

After a dictation session, look for recently modified files in the software's folders (AppData, ProgramData, install folder): logs, history, audio recordings, caches. Open the logs and search them for a sentence you dictated. Lean software keeps neither the sound nor the text, and its logs describe events, never the dictated content.

Después de una sesión de dictado, busque archivos modificados recientemente en las carpetas del software (AppData, ProgramData, carpeta de instalación): registros, historial, grabaciones de audio, caches. Abra los registros y busque en ellos una frase que haya dictado. Un software ligero no guarda ni el sonido ni el texto, y sus registros describen eventos, nunca el contenido dictado.

Nach einer Diktatsitzung suchen Sie nach kürzlich geänderten Dateien in den Ordnern der Software (AppData, ProgramData, Installationsordner): Protokolle, Verlauf, Audioaufnahmen, Caches. Öffnen Sie die Protokolle und durchsuchen Sie sie nach einem von Ihnen diktierten Satz. Eine schlanke Software speichert weder den Ton noch den Text, und ihre Protokolle beschreiben Ereignisse, niemals den diktierten Inhalt.

Ce que ces contrôles ne prouvent pasWhat these checks do not proveQué no demuestran estas comprobacionesWas diese Prüfungen nicht beweisen

Ils montrent ce que fait le logiciel aujourd'hui, sur ce poste. Ils ne garantissent rien pour la version suivante. D'où l'intérêt de figer les versions déployées, de vérifier leur signature, et de refaire ces contrôles à chaque mise à jour. Un éditeur sérieux doit vous y aider : liste des connexions prévues, emplacement des fichiers, réglages pour tout couper.

They show what the software does today, on this machine. They guarantee nothing for the next version. Hence the value of pinning deployed versions, checking their signature, and repeating these checks at each update. A serious vendor should help you do so: a list of expected connections, file locations, settings to switch everything off.

Ellos muestran lo que el software hace hoy, en esta máquina. No garantizan nada para la próxima versión. De ahí el valor de fijar las versiones desplegadas, verificar sus firmas y repetir estas comprobaciones en cada actualización. Un proveedor serio debería ayudarle a hacerlo: una lista de conexiones esperadas, ubicaciones de archivos, ajustes para desactivar todo.

Sie zeigen, was die Software heute auf diesem Rechner tut. Für die nächste Version garantieren sie nichts. Daher lohnt es sich, die eingesetzten Versionen festzulegen, ihre Signatur zu prüfen und diese Prüfungen bei jedem Update zu wiederholen. Ein seriöser Anbieter sollte Ihnen dabei helfen: eine Liste der vorgesehenen Verbindungen, die Speicherorte der Dateien, Einstellungen, um alles abzuschalten.
