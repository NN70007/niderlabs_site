Link your watch

  1. On the watch, tap the screen until SETTINGS appears.
  2. Type the 6-digit code it shows. It changes every few minutes.

No account, no password. The code only works for a few minutes and only for your watch. You can also change every setting in the Connect IQ app on your phone.
